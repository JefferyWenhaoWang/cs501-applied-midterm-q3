# CS501 Applied Midterm - Q3

## Lazy Lists

This project displays a scrollable list of 20 student names using Jetpack Compose.

## Features

- Uses `LazyColumn`
- Uses the `items()` DSL
- Displays each student name inside a Card
- Scrollable list UI

## How to Run

1. Open the project in Android Studio
2. Run the app on an emulator or Android device
3. Scroll through the student list
